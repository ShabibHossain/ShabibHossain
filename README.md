## About me

Self-taught developer from Bangladesh. I build games, Android apps, Minecraft mods, and a few things that probably shouldn't exist, like my own programming language. I learn by shipping stuff, breaking it, and fixing it.

- Building things in **Python** and **Kotlin**
- Making games in **Godot**
- Modding **Minecraft** with NeoForge and Forge
- Currently deep into low-level stuff: a compiler written in x64 assembly

## What I'm building

| Project | What it is | Stack |
|---|---|---|
| **Kova** | A custom programming language with a compiler written in x64 assembly for Windows | Assembly |
| **BIBI OS** | Custom Ubuntu-based Linux distro with KDE Plasma, built through GitHub Actions | Linux, xorriso |
| **Miku Companion Mod** | Hatsune Miku companion for Minecraft with taming, inventory, and AI chat | Java, NeoForge |
| **AI Video Editor** | Android video editor powered by ffmpeg-kit and the Groq API | Kotlin |
| **Aternos Controller** | Native Android app to control an Aternos Minecraft server from an old tablet | Kotlin |
| **Cloud Storage Mounter** | RaiDrive-style app that mounts Google Drive and Dropbox as drives on Windows | Python, WinFSP |
| **Minecraft House Generator** | Procedural house builder that places blocks through RCON | Python |
| **Godot Platformer** | 2D platformer built from scratch while learning Godot 4 | GDScript |
